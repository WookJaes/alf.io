# 직접 예약 링크

관리자의 티켓 카테고리 설정에서 코드를 지정하면 `/e/{event}/c/{code}` 링크로 예약을 시작할 수 있다. 기존 `/event/{event}/code/{code}` 경로도 지원한다.

공개 카테고리는 `?qty=N`으로 같은 카테고리의 티켓 N장을 하나의 예약으로 생성한다. 예를 들어 `/e/conference/c/PUBLIC?qty=3`은 3장을 예약한다. 생략하거나 `qty=1`이면 기존처럼 1장을 예약한다.

수량은 양의 정수여야 하며 기존 행사·카테고리 구매 한도와 재고 제한을 따른다. 빈 값, 숫자가 아닌 값, 0·음수·정수 범위 초과, 구매 한도 초과, 재고 부족이면 예약을 생성하지 않고 행사 페이지에서 기존 오류를 안내한다.

접근 제한 카테고리와 특별 가격 코드는 `qty`와 관계없이 기존처럼 1장을 예약한다. 할인 코드는 기존처럼 행사 페이지로 이동하여 할인을 적용한다. 소셜 미리보기 요청은 예약을 생성하지 않고 행사 페이지로 이동한다.
