# 청구 문서 Excel 내보내기

관리자 행사 화면의 Download 메뉴에서 all Billing Documents (Excel)을 선택한다. 기존 행사 소유권·조회 권한과 문서 조회 범위를 유지한다.

기존 컬럼 뒤에 다음 두 컬럼을 제공한다.

- `STATUS`: 문서에 연결된 예약의 현재 상태 코드. 문서 자체의 유효 상태가 아니다. 오프라인 결제 대기는 `OFFLINE_PAYMENT`, 확정은 `COMPLETE`, 취소는 `CANCELLED` 등 기존 예약 상태를 그대로 표시한다.
- `CONFIRMATION_DATE`: 예약에 저장된 확정 시각을 행사 시간대로 변환한 `yyyy-MM-dd HH:mm` 값. 확정 시각이 없으면 빈 값이다. 취소된 예약도 저장된 확정 시각이 있으면 표시한다.

`Generated on`은 청구 문서 생성 시각이며 예약 확정일과 다르다. 하나의 예약에 문서가 여러 개 있으면 모든 문서 행에 같은 현재 예약 상태와 확정 시각을 표시한다. 기존 조회 조건에서 포함되는 취소 예약의 문서도 그대로 포함한다.

기존 컬럼 이름·순서·값을 유지하고 이탈리아 전자청구 설정이 활성화된 경우에도 신규 두 컬럼을 맨 끝에 추가한다. 고정 컬럼 수로 Excel을 처리하는 도구는 마지막 두 컬럼의 추가를 반영한다. URL·요청 형식·예약 및 결제 처리·DB 스키마는 바뀌지 않는다.


관리자에 로그인했지만 해당 행사의 소유권이 없는 사용자의 Excel 요청은 HTTP 403과 권한 거절 메시지를 반환한다. 거절 시 청구 문서 데이터·Excel 파일·attachment 헤더를 제공하지 않는다.
