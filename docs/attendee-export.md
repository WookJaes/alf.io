# 참석자 데이터 내보내기

관리자 행사 화면의 참석자 내보내기에서 원하는 항목과 CSV 또는 Excel 형식을 선택한다.

- `E-Mail`: 티켓에 등록된 참석자의 이메일.
- `Reservation E-Mail`: 해당 티켓의 예약자 이메일. 예약자와 참석자가 다른 경우 구분해서 확인할 수 있다.

같은 예약의 티켓은 각 행에 같은 예약자 이메일을 표시한다. `Reservation E-Mail`을 선택하지 않으면 기존처럼 선택한 참석자 항목만 출력한다. 기존 내보내기 접근 권한과 추가 입력 필드를 유지한다.

내보낸 CSV에서 `ID`, `E-Mail`을 선택하면 [명단 비교](attendee-reconciliation.md)에 사용할 수 있다. 비교는 기존 내보내기와 같은 티켓 상태를 대상으로 하고 참석자 이메일을 비교한다. 기존 내보내기의 열 선택·파일 형식·권한은 유지한다.
